基础使用

A先把第一家站子存进去

完成最小使用流程：保存必要信息 → 复制调用配置，或直接打开网站。点步骤标题看操作。

准备好站点给你的网址、接口地址和 API 密钥。下面的示例都是假的，不可用于调用。

  1. 第一次打开，设置主密码

    第一次打开，输入两遍自己设置的主密码，点“创建我的密钥簿”。以后解锁和载入这份备份都要用它。已有备份就点“我已经有备份文件”，选择文件后输入导出那份备份时的主密码。

    这一页按按钮文字操作即可，不另配截图。主密码由你自己保管。

  2. 点“粘贴识别”，把整段信息贴进来

    就像粘贴快递地址，不必先拆成一栏一栏。贴完点“识别并检查”。

    网站名：示例站点
网站网址：（你自己的站点网址）
Base URL：（站点提供的接口地址）
API 密钥：（你自己的密钥）
令牌备注：写作用
分组：Coding 专用

    这只是填写格式。自己操作时，把括号里的内容换成自己的信息；教程里不展示可用网址或密钥。

  3. 看一遍填得对不对，再点“保存条目”

    检查网址、Base URL、密钥、分组和备注。有错就改，某一栏填乱了就点那一栏的 ×。同一站有多把密钥或多个地址，点对应区域“再加一个”。

    只填网址或 Base URL 之一时，会按常见格式补另一项；官网和 API 域名不同、接口不是 /v1 的站点，要自己核对改好。网站名、地址备注和密钥备注可不填，使用默认显示名。

  4. 回首页点这家站，复制配置或打开网站

    展开“Base URL”复制接口地址，在令牌旁复制密钥，填入自己的聊天或开发工具。网址右侧的方框箭头可直接拉起浏览器打开该站网站；眼睛按钮可显示 / 隐藏密钥。

    “复制 Base URL 与令牌”会合并复制第一条 Base URL 和这把密钥；要用备用地址，请单独复制它。蓝瞳负责整理配置，本身没有模型聊天功能。

基础使用

D按自己的习惯摆放，再选个颜色

点步骤标题展开图文；一次查看一个步骤，也可以直接跳到下一步。

  1. 常用的置顶，同类的分组

    打开站点详情点“设为常用”。编辑条目时在“分组”填“便宜”或“Coding 专用”等名字，再保存。设置里能统一改分组名。

    首页搜索框能检索站点名、网址、密钥备注、标签和自定义备注；临时找站时直接输入关键词。

  2. 回首页，长按拖到想放的位置

    也可以先点“排序”，拖完点“完成”。常用站点排在前面；常用与普通站点分别调整。总览里的余额排序不改变这里的位置。

  3. 右上角设置里选主题

    在“使用偏好”点冰蓝银白、深海星夜或奶油金；下拉框还可以选“跟随系统”。选完自动保存。

基础使用

E开指纹、做备份，换设备也有准备

点步骤标题展开图文；一次查看一个步骤，也可以直接跳到下一步。

  1. 想少输密码，就开启指纹

    手机先录好指纹。蓝瞳里打开“设置 → 加密与备份 → 开启指纹解锁”，按系统提示验证。之后在解锁页点“使用指纹解锁”。主密码仍要记住，指纹失效时还要用它。

  2. 添加或修改重要记录后，导出一份备份

    点“设置 → 加密与备份 → 导出加密备份”，在手机的文件界面选保存位置。生成的是加密 .json 文件；以后载入要用导出时的主密码。

  3. 换设备，把备份传过去再载入

    新设备首次打开时点“我已经有备份文件”；已经在用的设备点“设置 → 载入加密备份”。选中文件，再输入这份备份的主密码。

  4. 确认替换前，先备份当前设备的数据

    载入不是合并，会用备份内容替换当前记录。确认后，主密码沿用备份密码；需要的指纹、余额与日志查询要重新开启。升级 App 则先备份，再覆盖安装。

进阶使用

B再把这家站的账户余额查出来

点步骤标题展开图文；一次查看一个步骤，也可以直接跳到下一步。

这一部分需要 Android 版，以及站点开放兼容接口。普通 API Key 用来调用模型；查整个账户，要用数字用户 ID 和用户级访问令牌。站点登录密码不填进来。

  1. 在蓝瞳打开这家站的“账户余额 → 配置”

    先记住这里要填的三项：查询站点、数字用户 ID、用户级访问令牌。

  2. 到站点个人资料页，找自己的数字用户 ID

    先点用户图标，再点“个人资料”。在资料页找到用户 ID，填回蓝瞳的“站点用户 ID”栏。只填完整数字编号，不填用户名或邮箱。图中的私人信息已隐藏，操作时看自己的账户。

  3. 在“个人资料”或“安全与访问”里找访问令牌

    访问令牌通常在个人资料、安全设置或“安全与访问”中。找到下图的“访问令牌”项，点开后按站点提示获取该账户的用户级访问令牌，再填回蓝瞳。它与聊天工具使用的 API Key 不同。

    若能选择权限，优先使用站点提供的只读凭证。若只有“重新生成”，先核对站点说明，重新生成可能使旧凭证失效。找不到入口时可先跳过账户查询。

  4. 回蓝瞳填好，开启查询并保存

    查询站点通常填网站根地址，不带模型接口的 /v1；这里不展示具体网址。填入同一站点、同一账户的 ID 和访问令牌。开启本站查询，保存时核对将要发送凭证的目标。

    显示单位不确定就保留“额度点”。想显示人民币、美元或积分，要按站点规则核对单位和除数；常见的 500000 不是所有站都适用。

  5. 点 ￥，刷新后按余额排序

    “余额”看账户，“令牌”看已配置的单把密钥，“总消耗”看累计额度消耗。选择升序或降序；该站的 ⋯ 菜单里可以看查询时间、配置和日志。

    只想查一把 API Key 的额度，在配置中选“单个令牌额度”，填那把密钥。账户与令牌结果各自保存，不会相加。

  6. 配置已经填过，想一次开启所有站点？

    在 ￥ 总览选好“余额 / 总消耗”或“令牌”页签，点右上角“全部开启”。先看清目标列表和跳过原因，再确认。

    作用于所有站点，不受筛选限制。余额与总消耗页处理账户查询，令牌页处理令牌查询；各自独立。缺地址、凭证或数字 ID 的站点会跳过并列出原因。先为各站分别配置一次，备份恢复后就能批量重新开启。历史日志仍需在各站页面按需开启。

进阶使用

H查模型状态与跨站搜索

点步骤标题展开图文。七步配图采用安卓并装测试版的实拍截图，站点信息已遮盖。

平时查一家站，从站点详情进。想看哪些已收藏站点有同一个模型，从首页跨站搜。 主站读不到时按第 3—5 步补充来源。

  1. 打开单站的模型状态

    在「我的站点」打开一张站点卡片，在余额卡片下方点「模型状态」。

  2. 筛选当前站点的模型

    读到数据后，可以搜模型名或片段。展开「筛选与排序」，按成功率、延迟等条件缩小范围。

  3. 主站读不到？添加查询页

    展开「添加模型广场或公开监控页」，填入模型监控页或独立查询页的网址，点「保存并读取」。

  4. 切换统计来源

    查询页支持公开读取时，可从左上角「统计来源」选中对应来源，再查看该来源的结果。

  5. 仍读不到？打开原网页

    需要登录或蓝瞳暂时无法读取时，点右上角「打开原站状态页」，到浏览器查看。

  6. 用一个关键词查多个站

    回到「我的站点」，点「跨站搜模型」。输入模型名或片段，按需选分组和筛选条件，再点「搜索」。

  7. 核对来源，打开结果

    在「来源核对」里看哪些来源未命中、未读到或被筛掉。点结果右侧的「查看」，回到对应站点的模型状态。

模型状态取自蓝瞳能读取的公开数据。搜索未命中只说明本次公开查询没有找到结果，登录后可见的模型仍需到原站核对。

C查看调用、入账和订单记录

点步骤标题展开图文；一次查看一个步骤，也可以直接跳到下一步。

  1. 点这家站的“用量与日志”

    入口在站点详情，也可以点 ￥ 总览的“⋯ → 日志”。先完成账户查询配置；首次点“启用并查询”，核对目标站点后确认。

  2. 选你要看的记录，筛选后点“查询 / 刷新”

    “使用日志”看模型调用；“充值 / 入账”看站内额度变化；“支付订单”看站点返回的订单。展开筛选，选日期或填模型名、令牌备注，再查询；更多记录点下一页。

    每次打开默认查近 7 天，截至当前时间。点“查询 / 刷新”会重新取当前时间；主动改成自选日期时按所选范围查询。旧缓存会显示它自己的查询时间。

    筛选填密钥的备注名，不填完整密钥。支付订单按站点分页，不套用日志日期筛选；支付金额不套用余额换算。每个页签只缓存最近查的一页及概要。

遇到问题，先检查这几项

怎么和朋友交换站点清单？

食用推荐 → TXT 导出内容选“全部站点清单” → 导出 TXT。无需批量选择，一次整理全部站点的名称、网站地址、标签和自定义备注，不受当前搜索或分组筛选影响。清单不包含令牌、接口地址、账户 ID 和查询凭证字段。选择“食用推荐文案”则保留当前所选站点的评分与评价。

余额不对？

先看查的是账户还是某把密钥，再核对账户 ID、凭证、显示单位、换算除数和更新时间。旧缓存可能没更新，刷新后再和站点页面对照。

查不到余额或日志？

确认正在用 Android 版、该站查询已开启、ID 与凭证属于同一账户。接口没开放、站点改版或有验证限制时，可能无法拉取。失败保留旧结果，不会算成零。

“总消耗”有些站没数字？

先刷新账户；如果站点没有返回累计消耗，就保持“未提供”。只统计有数据的站点，页上会显示覆盖了多少家。历史消耗不是全部实付充值。

填好后退出，怎么没保存？

编辑表单要先点“保存条目”，回首页留意“已自动保存”。输入到一半就点取消，不会提交。主题和排序会自动保存。

识别错了，或剪贴板按钮没反应？

长按输入框手动粘贴，或改用手动新增。识别结果可逐栏修改，× 只清空对应栏。多密钥推荐一把后面跟一个备注，更容易检查对应关系。

关于查询与金额

蓝瞳按通用 New API 文档提供只读查询，特殊站点的接口、认证和返回格式可能不同，无法保证每家都能查。余额、消耗、历史范围与付款记录以站点页面和账单为准。蓝瞳不代为充值、交易或保管资金。网页版只保存配置和查看缓存，不实际拉取。

用户 ID 与账户访问令牌已补常见界面示例，各站入口仍可能不同；请以自己账户页面及站点说明为准。

关于本手册与配图

本手册已内置于 App，点主界面顶部的“帮助”即可打开，站点列表和余额总览都能进入。设置中的“帮助与反馈”与初次打开、锁定页的“使用手册”也保留入口。离线也能阅读，点右上角“返回 App”回到密钥簿。
